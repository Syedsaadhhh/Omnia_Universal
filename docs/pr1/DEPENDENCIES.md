## Validation and residual risk

- Baseline audit: 3 affected package entries (Next critical, PostCSS high, Sharp high), containing 23 unique advisories. The number of package entries is not the number of exploits.
- Current clean-lock dependency audit: 0 reported findings at all severities; [JSON](evidence/npm-audit-after.json). Audit checks the resolved production and development tree. This is a dated registry result, not a vulnerability-free guarantee.
- Regression coverage includes real production route rendering, OG generation, local image API rejection, keyboard/hydration behavior, contact contracts and security headers, plus pinned Docker build/runtime checks. See the checkpoint report for actual final outcomes.
- Production dependencies remain unchanged until an approved release. Provider native-image implementation and installed production transitive tree were not extracted or attacked. No payload exploits, source-map reads of real secrets or malformed-image native tests were performed.
- Future Next/React updates, dependency lifecycle requirements and native platforms must be reviewed; CI will fail on newly reported dependency advisories rather than silently ignore them. No audit suppressions are configured.
